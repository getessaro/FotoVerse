# 🎨 FotoVerse

**FotoVerse** é uma plataforma web interativa para explorar o mundo através de imagens inspiradoras. Com uma interface moderna, responsiva e cheia de estilo, o projeto foi desenvolvido com foco em **aprendizado de integração com APIs**, utilizando a [API do Unsplash](https://unsplash.com/documentation) para buscar imagens em tempo real.

## 🚀 Funcionalidades

- 🔍 Busca inteligente por temas (natureza, cidades, arte, etc.)
- 🌙 Modo escuro com bordas fluorescentes e animações pulsantes
- 📱 Design responsivo para desktop e mobile
- ⚡ Interface leve e rápida
- 🎨 Cards dinâmicos com imagens de alta qualidade

## 🛠️ Tecnologias

- HTML5
- CSS3 (com animações e media queries)
- JavaScript
- API do Unsplash
